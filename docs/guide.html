fpbrowser2api 使用指南

即梦 Seedance / SeedDream 反向代理 → NewAPI 兼容接口

一、架构概览

┌─────────────────────────────────────────────────────────────────────┐ │ 下游应用 (NewAPI / one-api / 你的业务) │ │ 调用: POST /v1/videos GET /v1/videos/{id} GET /v1/models │ └────────────────────────────────┬────────────────────────────────────┘ │ HTTP (Bearer API Key) ▼ ┌─────────────────────────────────────────────────────────────────────┐ │ fpbrowser2api (FastAPI, port 8000) │ │ ┌──────────┐ ┌──────────────┐ ┌────────────────────────────┐ │ │ │ 公开 API │ │ 任务队列/调度 │ │ 窗口池管理 (预热/健康检查) │ │ │ └──────────┘ └──────┬───────┘ └────────────┬───────────────┘ │ │ │ │ │ │ ▼ ▼ │ │ ┌─────────────────────────────────────────────────────────────┐ │ │ │ Task Executors (dreamina_workflow / veo_workflow / sora...) │ │ │ │ → Playwright CDP → 在浏览器页面内执行 fetch() │ │ │ └──────────────────────────────┬──────────────────────────────┘ │ └─────────────────────────────────┼───────────────────────────────────┘ │ CDP (Chrome DevTools Protocol) ▼ ┌─────────────────────────────────────────────────────────────────────┐ │ RoxyBrowser 指纹浏览器 (本地客户端, 提供 HTTP API) │ │ ┌────────┐ ┌────────┐ ┌────────┐ │ │ │ 窗口 1 │ │ 窗口 2 │ │ 窗口 N │ ← 每个窗口独立指纹/代理/Cookie │ │ └────┬───┘ └────┬───┘ └────┬───┘ │ └───────┼──────────┼──────────┼───────────────────────────────────────┘ │ │ │ ▼ ▼ ▼ ┌─────────────────────────────────────────────────────────────────────┐ │ 目标网站: dreamina.capcut.com (即梦/Seedance) │ │ sora.com / flow.google.com / grok.x.ai ... │ └─────────────────────────────────────────────────────────────────────┘
核心原理：不是直接逆向 HTTP 接口，而是通过指纹浏览器开真实窗口，用 Playwright 连上去，在页面上下文里执行 fetch() 调用即梦的内部 API。对即梦来说，你就是一个正常登录的用户在浏览器里操作。

二、关键概念

概念说明
Project (项目)顶层组织单位，一个项目对应一组浏览器服务器
Browser Server (浏览器服务器)一个 RoxyBrowser 实例的连接信息 (地址 + Token)
Space (空间)RoxyBrowser 里的 Workspace，包含多个窗口
Window (窗口)一个独立的浏览器实例，有自己的指纹、代理、Cookie
Task Type (任务类型)定义一种工作流，如 dreamina_workflow，绑定到具体窗口
Task (任务)一次具体的生成请求，排队 → 分配窗口 → 执行 → 完成
Window Binding (窗口绑定)将窗口分配给某个任务类型，含额度/并发配置

四、前置条件

  • ✅ Python 3.10 — 项目字节码严格要求 CPython 3.10.x
  • ✅ RoxyBrowser 指纹浏览器 — 需要安装客户端并开启本地 API
  • ✅ 即梦账号 — 至少一个已登录 dreamina.capcut.com 的账号
  • ✅ 代理 IP — 每个浏览器窗口建议配独立代理，避免风控
注意：RoxyBrowser 是商业软件，需要付费使用。每个即梦账号需要一个独立的浏览器窗口实例。

五、完整部署流程

安装并启动 fpbrowser2api

cd fpbrowser2api
./start.sh
# 或手动:
# python3.10 -m venv .venv && source .venv/bin/activate
# pip install -r requirements.txt
# python main.py

启动后访问 http://localhost:8000，用 admin/admin 登录管理后台。

安装并配置 RoxyBrowser

下载安装 RoxyBrowser 客户端，然后：

  • 创建一个 Workspace（工作空间）
  • 在 Workspace 里创建浏览器窗口（每个即梦账号一个窗口）
  • 为每个窗口配置独立的代理 IP
  • 开启 RoxyBrowser 的本地 API 服务，记下 API 地址和 Token

在浏览器窗口中登录即梦

打开每个 RoxyBrowser 窗口，手动访问 https://dreamina.capcut.com 并登录你的即梦账号。登录后保持窗口不要关闭（Cookie 会保存在窗口里）。

管理后台 → 创建项目结构

在 fpbrowser2api 管理后台 (/admin/projects) 中：

  1. 新建项目 — 起个名字即可
  2. 添加浏览器服务器 — 填写： 
    厂商 (vendor): roxy
局域网地址 (lan_addr): http://127.0.0.1:端口  (RoxyBrowser API 地址)
访问密钥 (access_key): 你的 RoxyBrowser API Token
  3. 添加空间 (Space) — 填入 RoxyBrowser 的 Workspace ID
  4. 同步窗口 — 点击同步按钮，自动拉取 RoxyBrowser 中的窗口列表

管理后台 → 创建任务类型并绑定窗口

在 /admin/task-types 中：

  1. 新建任务类型： 
    名称: Dreamina Seedance
代码 (code): dreamina_workflow
处理器 (handler): dreamina_workflow
刷新额度处理器: dreamina_credits
  2. 绑定窗口 — 将第 4 步同步过来的窗口绑定到这个任务类型
  3. 更新 access_token — 对每个绑定的窗口，点击"更新"读取浏览器中的 sessionid

测试调用

可以在管理后台的 /admin/test 页面手动提交测试任务，或直接调 API：

# 创建视频生成任务
curl -X POST http://localhost:8000/v1/videos \
  -H "Authorization: Bearer mirrmart_sora2_880315" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2",
    "prompt": "一只金毛犬在向日葵花田里奔跑",
    "duration": 10,
    "aspect_ratio": "16:9",
    "resolution": "720p"
  }'

# 返回 task_id，用它查询状态
curl http://localhost:8000/v1/videos/YOUR_TASK_ID \
  -H "Authorization: Bearer mirrmart_sora2_880315"

接入 NewAPI 进行二次转发

在 NewAPI 中添加渠道：

  • 类型：自定义渠道 / OpenAI 兼容
  • Base URL：http://你的服务器IP:8000
  • API Key：mirrmart_sora2_880315（或你在 setting.toml 里改的值）
  • 模型：seedance-2, seedance-2-fast, seedance-2-pro
项目已内置 /v1/chat/completions 健康检查端点（仅返回测试消息），NewAPI 的渠道测试可以通过。实际生成走 /v1/videos 接口。

六、API 接口参考

POST /v1/videos — 创建生成任务

{
  "model": "seedance-2",          // 必填: seedance-2 | seedance-2-fast | seedance-2-pro
  "prompt": "你的提示词",          // 必填: 生成描述
  "duration": 10,                 // 可选: 10 或 15 秒 (默认 10)
  "aspect_ratio": "16:9",        // 可选: 16:9, 9:16, 1:1, 4:3, 3:4 等
  "resolution": "720p",          // 可选: 480p, 720p, 1080p
  "image_url": "https://...",    // 可选: 图生视频的参考图 URL
  "image_urls": ["url1","url2"]  // 可选: 多参考图模式 (最多 9 张)
}

响应格式

{
  "id": "task_abc123",
  "task_id": "task_abc123",
  "object": "video",
  "created_at": 1714200000000,
  "status": "queued",            // queued → in_progress → completed | failed
  "progress": 0,
  "model": "seedance-2"
}

GET /v1/videos/{task_id} — 查询任务状态

{
  "id": "task_abc123",
  "status": "completed",
  "progress": 100,
  "video_url": "https://...",    // 生成的视频 URL
  "image_url": "https://...",    // 如果是图片任务
  "url": "https://...",          // 通用结果 URL
  "metadata": {
    "result_urls": ["https://..."]
  }
}

GET /v1/models — 列出可用模型

返回 OpenAI 兼容格式的模型列表，可被 NewAPI 自动识别。

八、注意事项 & 常见问题

Python 版本：必须是 CPython 3.10.x。项目核心代码以 .pyc 字节码分发，其他版本无法运行。

Q: 为什么需要 RoxyBrowser？能用其他指纹浏览器吗？

项目通过 RoxyBrowser 的 HTTP API 来管理浏览器窗口的开启/关闭和获取 CDP 连接地址。代码中 vendor 字段目前只支持 roxy。理论上可以适配其他指纹浏览器，但需要修改 fp_browser_client 模块。

Q: sessionid 会过期吗？

会。即梦的 Cookie 有有效期，过期后需要重新在浏览器窗口里登录。管理后台可以手动刷新 access_token。

Q: 一个窗口能同时处理多少任务？

每个窗口同一时间只处理一个任务（有 create lock 串行化）。并发能力取决于你绑定了多少个窗口。

Q: Cloudflare 拦截怎么办？

项目内置了 Cloudflare/Turnstile 检测和自动处理（等待、点击、窗口重启）。如果频繁触发，建议更换代理 IP 或降低请求频率。

Q: 和 iptag/jimeng-api 的区别？

jimeng-api 是纯 HTTP 逆向，轻量但脆弱；fpbrowser2api 是真实浏览器驱动，重但抗风控能力强。fpbrowser2api 还支持多平台（Sora、VEO、Grok），是通用框架。

总结：部署的核心路径是 → 装 RoxyBrowser → 开窗口登录即梦 → fpbrowser2api 后台配置项目/服务器/空间/窗口 → 创建 dreamina_workflow 任务类型并绑定窗口 → 通过 /v1/videos API 调用。接入 NewAPI 时用 Base URL + API Key 即可。
